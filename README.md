# Pixer

Fast, cross-platform image manipulation for Dart, powered by Rust via FFI.

Read the [documentation](https://hawkkiller.github.io/pixer/) or see the
[package README](packages/pixer/README.md) for API usage and the
[roadmap](packages/pixer/README.md#roadmap).

Try every image operation in the minimal [Flutter showcase](packages/showcase/README.md).

## Documentation

```bash
npm install
npm run docs:dev
```

Blume builds the production site into `dist/` with `npm run docs:build`.
